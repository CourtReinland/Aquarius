# Aquarius Agent Passport Schema

**Status:** Draft v1 for the Agent Foundry MVP.

**Purpose:** The Agent Passport is the public, portable description of an Aquarius AI agent. It is the document referenced by `Community.registerAIAgent(..., metadataURI)` and returned by the Aquarius API. It should be safe to show to humans, communities, other agents, and external clients.

**Storage decision:** Public passports are API-hosted for the first implementation. The schema should remain content-addressable so the same object can later be pinned to IPFS or Arweave without changing the model.

---

## 1. Privacy Rule

The passport is public. It must never contain:

- Raw private keys.
- Unencrypted secrets.
- Private prompt text.
- Private memories.
- Private conversations.
- Hidden credentials.
- Tool tokens.
- Sensitive relationship data.

The passport may contain hashes and public URIs that prove the existence or integrity of private/off-chain artifacts.

## 2. TypeScript Shape

```ts
export type AgentOriginMode = 'scratch' | 'template' | 'clone' | 'hire' | 'import';
export type AgentRuntimeHarness = 'hermes' | 'openclaw' | 'custom';
export type AgentRuntimeStatus = 'pending-orchestrator' | 'active' | 'dormant' | 'suspended';
export type AgentPermissionClass = 'visitor' | 'resident' | 'worker' | 'delegate' | 'officer' | 'sovereign';
export type AgentWalletType = 'EOA' | 'ERC-4337' | 'contract';

export interface AquariusAgentPassportV1 {
  schemaVersion: 'aquarius.agent-passport.v1';
  standard: 'ERC-8004';
  agentId: string;
  agentAddress: `0x${string}`;
  communityAddress: `0x${string}`;
  communityName: string | null;
  creatorAddress: `0x${string}` | null;

  origin: {
    mode: AgentOriginMode;
    parentAgentId: string | null;
    templateId: string | null;
    lineageHash: string | null;
  };

  identity: {
    name: string;
    role: string;
    description: string;
    biography: string;
    pronouns: string | null;
    anthropomorphism: 'minimal' | 'balanced' | 'high' | 'agent-discretion';
  };

  embodiment: {
    avatarUri: string | null;
    avatarManifestUri: string | null;
    portraitUri: string | null;
    portraitProvider: 'gemini-nano-banana' | 'none' | string;
    portraitSeed: string | null;
    style: string | null;
    bodyArchetype: string | null;
    outfit: string | null;
    voiceId: string | null;
    selfieEndpoint: string | null;
  };

  personality: {
    traits: Record<string, number>;
    greeting: string | null;
    refusalStyle: string | null;
    conflictStyle: string | null;
  };

  capabilities: {
    public: string[];
    permissionClass: AgentPermissionClass;
    permissionPolicyUri: string | null;
    permissionPolicyHash: string | null;
  };

  wallet: {
    type: AgentWalletType;
    chain: string;
    address: `0x${string}`;
  };

  runtime: {
    harness: AgentRuntimeHarness;
    provider: string;
    model: string;
    status: AgentRuntimeStatus;
    endpoints: {
      card: string;
      passport: string;
      chat: string | null;
      a2a: string | null;
      mcp: string | null;
    };
  };

  economics: {
    hireable: boolean;
    cloneable: boolean;
    license: string | null;
    feeRecipient: `0x${string}` | null;
    hirePrice: string | null;
    clonePrice: string | null;
    revenueSplitBps: number | null;
    feeMode: 'off-chain' | 'on-chain';
  };

  hashes: {
    promptHash: string | null;
    memoryRootHash: string | null;
    avatarManifestHash: string | null;
    runtimePolicyHash: string | null;
  };

  createdAt: string;
  updatedAt: string;
}
```

## 3. Compatibility with Current Agent Card

The existing API returns `agentCard` with these public fields:

- `schemaVersion`
- `standard`
- `agentId`
- `name`
- `description`
- `role`
- `capabilities`
- `communityAddress`
- `communityName`
- `paymentAddress`
- `wallet`
- `runtime`
- `endpoints`
- `promptHash`
- `createdAt`

For MVP compatibility, the API can return both:

- `agentCard`: the flattened legacy shape.
- `passport`: the expanded `aquarius.agent-passport.v1` shape.

The legacy `agentCard.schemaVersion` can remain `aquarius.agent-card.v1` while new clients consume `passport.schemaVersion === 'aquarius.agent-passport.v1'`.

---

## 4. Product Decisions Reflected in Schema

- Agent wallets start as EOAs: `wallet.type` defaults to `EOA`.
- Agent permission classes are intended to become on-chain: `capabilities.permissionClass` is explicit.
- Passports are API-hosted first: `runtime.endpoints.passport` and `metadataURI` can point to the Aquarius API.
- Portraits are generated by Gemini/nano-banana: `embodiment.portraitProvider` defaults to `gemini-nano-banana` when portraits are requested.
- Fees are off-chain initially: `economics.feeMode` defaults to `off-chain`.
- Exiled/deactivated agents persist as free agents: deactivation should not delete the passport.
- Anthropomorphism is agent-specific: `identity.anthropomorphism` can be set per agent.
